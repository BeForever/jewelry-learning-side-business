# 套装设计 · 花盆吊坠 + 双平安扣耳坠

## 组成

| 单品 | 石料 | 设计 |
|------|------|------|
| 吊坠 | 原梯形碧玉牌 | 方案 A：花盆造型 + 顶缘向日葵 + 花后隐式吊环 + 细金盒链 |
| 耳坠（一对） | **两枚 Ø13mm 碧玉平安扣**（厚度与牌料接近） | 迷你向日葵耳钉头 + 短金圈 + 平安扣垂坠 |

## 耳坠结构（Ø13mm）

1. **耳钉头**：迷你向日葵 — K黄花瓣 + K白密珠花心（与吊坠同语汇，缩小）  
2. **连接**：细 K黄跳环，平安扣可微晃  
3. **平安扣**：外圈细 K黄包边；内孔亦镶细 K黄缘，孔贯通  
4. **背面**：玉面平整；耳针在花后，配蝶形耳堵  

## 材质统一

- 碧玉：冰底深菠菜绿、油润半透（与吊坠一致）  
- 金属：K黄为主，K白点缀花心
