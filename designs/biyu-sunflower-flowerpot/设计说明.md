# 碧玉 · 向日葵花盆镶嵌设计说明

## 设计概念

以碧玉本体作「花盆」器身，梯形包边（**上长下短**）强化花盆轮廓；顶缘居中做立体向日葵，整体读成「一盆向日葵」。

## 结构要点

| 部位 | 材质 / 工艺 | 说明 |
|------|-------------|------|
| 器身 | 冰底碧玉（客户原石） | 上宽下窄软圆角；**深菠菜绿、色匀油润**，冰底半透（边角透光），贴原石实拍 |
| 包边 | 建议 18K 黄 | 细包边跟形；顶边可略作口沿感 |
| 花瓣 | K 黄 | 尖瓣细棱，立于顶缘正中 |
| 花心 | K 白 | 密珠肌理模拟葵盘 |
| 叶饰（可选） | K 白 | 可按顶宽增减 |

## 比例建议（V3）

- 贴原石：顶宽仅略大于底宽（约 **1.15～1.25:1**），牌面接近「宽≈高」的短花盆，忌拉高、忌收腰过狠
- 向日葵直径约顶边 **1/3**，玉面为主、花为点睛
- 花心略凸；侧视花头坐于口沿之上

## 吊挂方案对照（供选）

| 方案 | 做法 | 观感 |
|------|------|------|
| A | 花后隐式吊环 + 细金链 | 原方案，正面干净 |
| B | 顶缘左右小环 + 深色绳 | 左右对称，略见环 |
| C | 花座下暗穿绳（绳从花下左右出） | 几乎不见金属扣 |
| D | 花心顶部单环穿链 | 吊点居中，环略外露 |
| E | 花顶造型小 bail + 盒式金链 | 装饰感强 |
| F | 顶角微孔/暗管 + 绳结 | 无金属扣头感 |
| G | 顶缘左右双环 + 粗金链 | 稳、偏厚重 |

正稿吊挂待客户选定；主体造型仍以 V4 为准。

## 佩戴 / 穿绳

### 原方案（V4）

- **吊挂位置**：向日葵 **背后** 细小 **K黄吊环**，穿链或穿绳
- 正面花盆 + 顶缘向日葵，吊环藏花后

### V5（已弃用）

顶缘左右对穿大孔绳 — 观感不佳

## 原石提取要点

- 实拍上短下长 → 设计竖直翻转成上长下短
- **冰底**：半透、水头足、边缘可见透光，非不透明死绿
- 色匀深菠菜绿，无黑点花斑；指甲盖级小牌
