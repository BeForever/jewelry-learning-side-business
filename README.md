# jewelry-learning-side-business

这是一个长期维护的「珠宝学习 + 自媒体运营 + 副业变现」项目。

项目目标：从零系统学习珠宝/宝石学，持续记录学习过程，并同步运营一个定位为「珠宝小白自学宝石学，边学边拆解珠宝消费坑」的自媒体账号。后续在知识、内容和信任积累的基础上，逐步探索低风险副业变现。

## 项目定位

- 学习主线：普通地质学、矿物学、晶体学、岩石学、宝石学、钻石、彩色宝石、翡翠玉石珍珠、估价与市场。
- 内容主线：用小白视角记录真实学习过程，拆解珠宝消费中的信息差、预算误区和风险点。
- 副业主线：先做内容与信任，再做轻服务，最后谨慎尝试低客单商品与定制服务。

## 多媒体学习原则

- 纯概念课可以文字为主，但涉及结构、对比、观察方法时，应尽量配图。
- 涉及光泽、火彩、切工、仪器操作、佩戴场景时，应优先考虑短视频或动图。
- 每节课至少判断一次：是否需要配图、视频、实物照片或分镜脚本。
- 每节课面向自媒体发布时，默认维护关键配图、短视频分镜、分屏视频脚本和图文轮播稿。

## 表达原则

- 真诚记录学习过程，不装专家。
- 讲证据、讲预算、讲风险、讲适合。
- 不做真假鉴定、估价结论、产地判断。
- 高价货建议证书、复检和专业机构判断。

## 副业路线

- 0-6 个月：纯内容期。
- 6-12 个月：低价证书解读、预算选购建议、陪看服务。
- 12-18 个月：珍珠轻珠宝、银镶彩宝、入门彩宝等低客单商品。
- 18 个月以后：定制、婚礼珠宝、纪念日礼物和稳定私域客户。

## 风险红线

- 不碰无证书高价货、直播间口头承诺、老翡翠古董、高价红蓝宝/祖母绿/翡翠手镯。
- 不说一眼假、内幕、源头价、包升值、千万别买。
- 不垫大额库存，不赊账拿货。
