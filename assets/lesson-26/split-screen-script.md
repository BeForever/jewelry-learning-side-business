# 第 26 课分屏视频脚本：彩色宝石总览：颜色、产地、处理和证书

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」或「上半屏讲概念 / 下半屏做避坑翻译」的分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-5s | 第 26 课：彩宝总览 | 先别被一个词带跑 | 彩宝要把颜色、处理、产地和证书拆开看。 |
| 5-18s | 颜色：色调/饱和度/明度/均匀度 | 直播图不够，要看多光源 | 颜色是重点，但不是一句“好看”就够。 |
| 18-32s | 处理：加热/扩散/充填/注油/染色 | 常见不等于可以不披露 | 处理类型和程度会影响价值、保养和预算。 |
| 32-45s | 产地：证书意见 vs 口播故事 | 名产地不是购买结论 | 产地必须看证据，不能只听故事。 |
| 45-60s | 证书：品种/颜色/处理/产地/日期 | 读备注，不只看天然 | 证书字段要和实物、复检、售后一起核对。 |
| 60-75s | 预算：学习/佩戴/礼物/高价 | 高价 = 证书 + 披露 + 复检 | 用途不同，预算取舍不同。 |

## 画面素材

- 主图：`colored-gemstone-overview.png`
- 左/上屏：术语卡片和框架图。
- 右/下屏：对应消费问题和红线。

## 字幕模板

- 颜色好，只是开始，不是结论。
- 处理要说清类型和程度。
- 产地故事需要证书支持。
- 高价彩宝必须支持复检。

## 剪辑备注

- 每个重点用不同颜色卡片，避免信息拥挤。
- 禁止出现“一眼鉴定”“稳赚升值”“源头内部价”等引导。
- 结尾引导评论区提问，不引导私信估价。
