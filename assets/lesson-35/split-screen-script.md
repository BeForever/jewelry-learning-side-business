# 第 35 课分屏视频脚本：欧泊入门：变彩、保养和拼合风险

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-6s | 标题：欧泊入门 | 不只看“花” | 欧泊变彩很美，但价值判断不止一个词。 |
| 6-20s | 变彩：亮度、色彩、图案、覆盖、多角度 | 强光最佳角度不够 | 要看普通光和多角度表现。 |
| 20-34s | 黑欧泊 / 白欧泊 / 火欧泊 | 类型不同，逻辑不同 | 火欧泊不一定强变彩，黑欧泊重底色衬托。 |
| 34-50s | 二层 / 三层拼合 | 必须披露 | 拼合可以买，但不能按整块天然欧泊定价。 |
| 50-64s | 注胶 / 染色 / 烟熏 / 糖酸 | 处理影响价值和稳定性 | 高价要看证书和复检。 |
| 64-78s | 干燥 / 温差 / 化学品 / 超声波 | 保养边界写进预算 | 欧泊更适合温和佩戴和低碰撞位置。 |

## 画面素材

- 主图：`opal-play-of-color-care.png`
- 左屏放术语，右屏放“买前问题”和“保养红线”。
- 用温差、香水、超声波图标做快速禁忌提示。

## 字幕模板

- 欧泊不是越花越值钱。
- 拼合欧泊必须披露。
- 避免干燥、强温差、化学品和超声波。

## 剪辑备注

- 展示变彩时要给多个角度，不只剪最闪一秒。
- 拼合段要避免说“拼合是假货”，重点是披露、价格和保养边界。
