# 第 28 课分屏视频脚本：蓝宝石入门：颜色体系、加热、扩散和预算

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」或「上半屏讲概念 / 下半屏做避坑翻译」的分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-5s | 第 28 课：蓝宝石 | 不只蓝色 | 蓝宝石是刚玉家族的多颜色体系。 |
| 5-18s | 蓝/粉/黄/紫/变色 | 名称先看证书 | 帕帕拉恰、变色等说法要核对字段。 |
| 18-32s | 蓝色：色调/饱和度/明度/均匀度 | 皇家蓝不能只听口播 | 颜色名不是自动高价。 |
| 32-45s | 加热：市场常见 | 披露清楚可比较 | 加热状态要和价格匹配。 |
| 45-60s | 扩散：重点风险 | 必须看 treatment/comments | 扩散不能用“优化”含糊带过。 |
| 60-75s | 预算：佩戴/礼物/学习/高价 | 高价要复检 | 用途不同，颜色、大小和处理取舍不同。 |
