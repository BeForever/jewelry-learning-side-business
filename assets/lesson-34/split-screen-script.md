# 第 34 课分屏视频脚本：金绿宝石、亚历山大石和猫眼效应

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-6s | 金绿宝石 chrysoberyl | 不是绿柱石 beryl | 名字相似，但矿物不同。 |
| 6-20s | 普通金绿宝石 / 亚历山大石 / 猫眼 | 同矿物体系，不同价值重点 | 先分清品类，再谈价格。 |
| 20-36s | 亚历山大石：变色效应 | 必须说明光源 | 会变色只是线索，不是天然结论。 |
| 36-52s | 猫眼效应：平行内含物 + 弧面 | 眼线看细直亮居中 | 一条亮线不等于金绿宝石猫眼。 |
| 52-66s | 合成 / 仿冒 / 替代材料 | 高价必须证书 | 视频效果不能替代检测。 |
| 66-78s | 证书 / 复检 / 样品对应 | 没证据不谈收藏级 | 权威证书是交易前提。 |

## 画面素材

- 主图：`chrysoberyl-alexandrite-catseye.png`
- 左屏放英文对比：beryl / chrysoberyl。
- 右屏放消费提醒：光源、天然性、证书、复检。

## 字幕模板

- 金绿宝石不是绿柱石。
- 会变色，不等于天然亚历山大石。
- 有猫眼，不等于金绿宝石猫眼。

## 剪辑备注

- 变色段必须标注冷光/暖光或日光/白炽灯等条件。
- 猫眼段用“效应”和“品类”分开字幕，避免观众混淆。
