# 第 16 课分屏视频脚本：比重与密度：手感、静水称重和消费边界

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」或「上半屏讲概念 / 下半屏做避坑翻译」的分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-5s | 第 16 课：比重与密度 | 压手不等于真 | 今天拆「压手」这个常见话术。 |
| 5-15s | 密度：单位体积质量 | 大小会影响手感 | 重量和密度不是一回事。 |
| 15-30s | 比重 SG：相对水密度 | 是材料线索 | SG 有用，但不能单独判价值。 |
| 30-45s | 静水称重：空气重/水中重 | 气泡和悬挂会误差 | 操作条件决定数据能不能解释。 |
| 45-60s | 镶嵌/空心/拼合/裂隙 | 成品数据要谨慎 | 成品重量不是宝石本身比重。 |

## 画面素材

- 主图：`specific-gravity-density.png`
- 左/上屏：重量、密度、SG、静水称重公式。

## 字幕模板

- 压手感是主观观察，不是鉴定证据。
- 静水称重需要合适样品和规范操作。
- 镶嵌、空心、拼合会干扰比重判断。
- 高价货看证书、复检和专业检测。

## 剪辑备注

- 画面避免演示高价货泡水。
- 可用动画表示空气中重量和水中重量。
- 结尾提醒「不建议自行测试怕水或高价样品」。
