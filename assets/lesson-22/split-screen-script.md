# 第 22 课分屏视频脚本：钻石颜色净度深入：肉眼可见与预算取舍

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」或「上半屏讲概念 / 下半屏做避坑翻译」的分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-5s | 标题：第 22 课颜色净度 | 标题：别被最高级带焦虑 | 高等级通常更贵，但不一定最适合每个预算。 |
| 5-15s | D-Z：白钻体色 | 消费提醒：肉眼无色看场景 | D-F 更接近无色，G-J 常见近无色，但还要看大小、切工和金属颜色。 |
| 15-30s | 净度：类型/位置/大小 | 消费提醒：问肉眼可见吗 | 净度不是只看 VS、SI，台面中央黑点和边缘小点观感不同。 |
| 30-45s | 预算：切工/克拉/颜色/净度 | 消费提醒：先保看得见的效果 | 预算固定时，先保可靠证书、切工和肉眼效果。 |
| 45-60s | 证书图/实物视频/复检 | 风险边界：不凭等级估价 | 我是学习者，不做鉴定、估价或产地结论。 |

## 画面素材

- 主图：`diamond-color-clarity-budget.png`

## 字幕模板

- 肉眼无色，不等于证书最高色。
- SI 不是自动不能买，VS 也不是自动完美。
- 先问瑕疵在哪里，再谈能不能接受。
- 我是学习者，不做鉴定或估价结论。

## 剪辑备注

- 节奏：每 10-15 秒切换一次重点。
- 字幕：避免使用“必买 D 色”“SI 都垃圾”“包保值”等绝对化话术。
- 结尾：引导评论区讨论预算取舍，不引导私信高价代购。
