# 第 32 课分屏视频脚本：石榴石族入门：不只有酒红色

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-6s | 标题：石榴石族 | 不只酒红色 | 石榴石是一族宝石，不是一种颜色。 |
| 6-20s | 铁铝 / 镁铝 / 锰铝 / 钙铝 / 钙铁 | 先问是哪一种 | 成员不同，颜色和价格逻辑不同。 |
| 20-35s | 红、橙、绿、紫 | 颜色只是线索 | 红色会太暗，橙色看偏褐，绿色先分品种。 |
| 35-50s | 沙弗莱 / 芬达 / 翠榴石 | 市场名称要看证书 | 不能把所有绿色都叫沙弗莱。 |
| 50-62s | 相对少处理 | 别绝对化 | 少处理不等于不用证书。 |
| 62-75s | 通常无明显解理 | 佩戴友好但别硬碰硬 | 戒指仍要防摩擦和撞击。 |

## 画面素材

- 主图：`garnet-group-overview.png`
- 左屏放族群成员，右屏放购买问题。
- 可以用颜色卡转场：酒红、橙、鲜绿、紫红。

## 字幕模板

- 石榴石是一族，不是一色。
- 绿色外观不能自动等于沙弗莱。
- 相对少处理，不等于高价不用证书。

## 剪辑备注

- 不用“低端石榴石”概括红色品种，避免误导。
- 讲沙弗莱和翠榴石时要强调证书名称，而不是只看绿色。
