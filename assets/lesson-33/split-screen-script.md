# 第 33 课分屏视频脚本：海蓝宝、摩根石与绿柱石家族

用途：用于 9:16 竖屏短视频，采用「左侧知识点 / 右侧消费提醒」分屏形式。

## 分屏结构建议

| 时间 | 左/上屏：知识点 | 右/下屏：消费翻译 | 口播重点 |
| --- | --- | --- | --- |
| 0-6s | 标题：绿柱石家族 | 同族，不同买法 | 海蓝宝、摩根石、祖母绿是亲戚。 |
| 6-18s | 祖母绿 / 海蓝宝 / 摩根石 | 颜色来自不同微量元素 | 同一矿物家族可形成不同商业品种。 |
| 18-32s | 海蓝宝：蓝到蓝绿色 | 常见加热，看颜色浓度 | 加热要披露，颜色不能只看强光。 |
| 32-46s | 摩根石：粉色、粉橙色 | 常偏淡，看灰调和漏光 | 成品粉感可能被玫瑰金托出来。 |
| 46-62s | 祖母绿：绿色绿柱石 | 裂隙和油处理更关键 | 不能用海蓝宝佩戴经验套祖母绿。 |
| 62-75s | 证书 / 处理 / 场景 | 高价必须信息清楚 | 买前确认品种、处理、佩戴和复检。 |

## 画面素材

- 主图：`beryl-family-aquamarine-morganite.png`
- 左屏展示家族树，右屏展示“消费翻译”。
- 海蓝宝段用冷蓝色，摩根石段用粉橙色，祖母绿段用绿色。

## 字幕模板

- 同属绿柱石，不等于价格接近。
- 海蓝宝常见加热，但仍要披露。
- 祖母绿要单独看裂隙和油处理。

## 剪辑备注

- 避免把祖母绿讲成普通日常耐戴宝石。
- 海蓝宝和摩根石段要提示自然光观察，避免强灯误导。
