# 第 23 课：钻石荧光、奶咖绿、证书备注与隐藏风险

## 1. 本课核心笔记

### 1.1 本课重要结论

这一课先记住 4 个结论：

1. 钻石除了 4C，还要关注荧光、奶咖绿和证书备注。
2. 强荧光不一定都不能买，但需要看是否影响通透感和价格。
3. 奶、咖、绿是消费中常提到的观感风险，需要实物和专业判断。
4. 高价钻石应核对证书、实物视频、腰码和复检支持。

一句话总结：

> 本课材料已备好，正式学习时重点区分“观察描述”和“购买结论”；高价货继续回到证书、复检和专业机构判断。

### 1.2 为什么学习这一课

这一课把前面学过的矿物学、宝石学仪器、证书和消费风险连接到具体品类或购买场景中。目标不是立刻做鉴定或估价，而是为后续正式学习准备一套清晰的概念框架和自媒体表达素材。

### 1.3 荧光

紫外光反应 是这一课的核心观察点之一。学习时要把它放到具体品类、预算和证书语境中理解；强弱影响观感，但不能把单一信息点直接升级成鉴定、估价或产地结论。

### 1.4 奶咖绿

透明感/色调问题 是这一课的核心观察点之一。学习时要把它放到具体品类、预算和证书语境中理解；需实物确认，但不能把单一信息点直接升级成鉴定、估价或产地结论。

### 1.5 备注

证书附加信息 是这一课的核心观察点之一。学习时要把它放到具体品类、预算和证书语境中理解；不能跳过，但不能把单一信息点直接升级成鉴定、估价或产地结论。

### 1.6 消费边界

本课涉及的信息都只能作为学习和提问框架。真正购买时仍要看材料类别、证书、处理情况、预算、售后、复检支持和专业机构意见。不要用单一卖点做冲动决策。
