# 第 20 课：钻石证书与预算：天然钻、培育钻和购买决策

## 1. 本课核心笔记

### 1.1 本课重要结论

这一课先记住 5 个结论：

1. 钻石购买要先明确预算、用途和接受范围。
2. 天然钻和培育钻形成方式不同，价格逻辑和转售预期不同。
3. 证书要核对编号、4C、荧光、备注和尺寸比例。
4. 不要只追求参数拉满，适合预算和佩戴场景更重要。
5. 高价钻石建议复检、核对腰码和证书一致性。

一句话总结：

> 本课材料已备好，正式学习时要把“观察线索”和“鉴定/估价/购买结论”分开，高价货继续回到证书、复检和专业机构判断。

### 1.2 为什么学习这一课

这一课属于宝石学基础与消费决策之间的连接课。它的目标不是让你立刻成为鉴定师，而是让你以后看证书、看仪器结果、看商家话术时，知道哪些是证据，哪些只是描述，哪些需要继续核实。

![钻石证书与预算决策](../assets/lesson-20/diamond-certificate-budget.png)

### 1.2 先定预算和用途

买钻石前先问：是日常佩戴、婚戒、纪念日礼物，还是收藏？不同用途对应不同预算和参数优先级。

### 1.3 天然钻和培育钻

天然钻来自自然地质过程，培育钻由人工环境生长。二者都可以是真钻，但价格、稀缺逻辑和心理接受度不同。

### 1.4 证书怎么看

重点核对证书编号、4C、荧光、尺寸比例、净度图和备注。不要只看商家截图，要能官网查询。

### 1.5 消费边界

钻石不建议用“保值升值”做新手购买理由。预算内选择适合自己的参数组合，比盲目追求顶配更重要。

## 3. 可交互作业

### 作业 1：概念判断

请回答下面问题，并尽量说明理由：

1. 天然钻和培育钻都可以叫钻石吗？
2. 钻石证书重点核对哪些信息？
3. 为什么不建议新手用升值逻辑买钻石？
4. 预算有限时应该如何取舍 4C？

### 作业 2：自媒体表达改写

把这句话改成更稳妥的小白学习表达：

> 钻石一定保值，买越贵越好。

建议改写：

> 钻石购买应先看预算、用途、证书和参数组合，不建议把保值升值作为新手购买理由；高价购买要复检。

### 作业 3：消费场景追问

如果在柜台、直播间或私域里听到类似说法，请至少追问：

1. 证书或检测依据是什么？
2. 是否说明处理、合成、仿制或其他限制？
3. 价格和预算是否匹配？
4. 是否支持复检和售后？
