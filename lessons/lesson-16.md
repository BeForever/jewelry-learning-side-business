# 第 16 课：比重与密度：手感、静水称重和消费边界

## 1. 本课核心笔记

### 1.1 本课重要结论

这一课先记住 6 个结论：

1. 密度是单位体积的质量，比重 SG 是材料密度与水密度的相对值；它们能帮助理解「同样大小为什么有的更重」。
2. 手感、压手感、坠手感都是主观体验，会被尺寸、形状、镶嵌金属、空心结构和心理预期影响，不能单独判断真假或价值。
3. 静水称重通过「空气中重量」和「水中重量」估算比重，原理清楚，但对天平精度、悬挂方式、气泡、温度和样品状态有要求。
4. 镶嵌成品、空心结构、拼合材料、裂隙、孔洞、附着金属和胶都会改变测量结果，让比重数据失去单一材料意义。
5. SG 是证据之一，适合和折射率、偏光镜、分光、放大观察、证书共同使用，不适合独立做高价消费判断。
6. 对消费者来说，学习比重的重点不是在柜台掂重量，而是识别「特别压手所以一定真」这类话术的漏洞。

一句话总结：

> 比重能帮助区分材料，但手感不等于检测，静水称重也有样品边界；成品、空心、拼合和镶嵌都可能让数据失真。

### 1.2 为什么学习比重与密度

很多人买珠宝时会听到「这个很压手」「这个密度高」「这个轻飘飘肯定不对」。这些说法听起来直观，因为重量是我们能直接感受到的。但直观不等于可靠。一个小而厚的金属镶嵌成品可能很压手，一件空心金饰可能显得轻，一个大体积低密度材料也可能因为尺寸大而让人觉得不轻。

宝石学里，密度和比重确实有用。不同材料有不同密度范围，例如钻石、刚玉、石英、绿柱石、玻璃、塑料和某些仿制品之间可能存在明显差异。比重数据可以帮助排除一部分不可能选项。

但消费场景里最容易出问题的是：把手感当数据，把数据当结论，把成品的整体重量当单一宝石的密度。学习这一课，就是为了把「重量感」「比重测试」「消费判断」三件事分开。

### 1.3 密度、比重和重量感

密度指单位体积的质量。比重 SG 在宝石学里通常指材料密度相对于水的密度的比值。水的密度约为 1，所以如果某材料 SG 约为 3，入门理解就是同体积下它大约是水的 3 倍重。

先分清三个词：

| 概念 | 说明 | 消费误区 |
| --- | --- | --- |
| 重量 | 一个物体总共多重 | 大不一定密度高，可能只是体积大 |
| 密度 | 单位体积质量 | 需要知道体积，不能只靠手掂 |
| 比重 SG | 与水密度相比的相对密度 | 是材料线索，不是价值结论 |

举例：一颗体积较大的玻璃仿制品，拿在手里可能不轻；一颗体积小但密度较高的宝石，手感未必特别明显。镶嵌成品里，金属戒托、吊坠扣、链子、封底、胶和其他配件都会影响整体重量。消费者掂到的常常是「整件货的重量感」，不是「宝石本身的比重」。

### 1.4 为什么手感不可靠

「压手」是很典型的消费话术。它不是完全没意义，但它太容易被干扰。

| 干扰因素 | 为什么会影响手感 |
| --- | --- |
| 体积大小 | 大件物品即使密度不高，也可能有重量感 |
| 形状厚薄 | 厚实造型比薄片更压手 |
| 镶嵌金属 | 金、银、铜合金等会增加整体重量 |
| 空心结构 | 外观看着大，实际质量可能低 |
| 拼合结构 | 不同层材料密度不同，手感是综合结果 |
| 温度触感 | 冷、热、导热快慢会影响主观判断 |
| 心理预期 | 以为贵重材料应当压手，容易自我暗示 |

手感适合作为「我注意到它重量感如何」的描述，不适合作为「它一定是真的、天然的、高价值的」证据。尤其是珠串、手镯、雕件和镶嵌成品，尺寸和结构差异非常大，靠手感判断风险更高。

稳妥表达应该是：「这件东西拿起来有明显重量感，但重量感可能来自体积、金属或结构，仍需要证书和检测。」不稳妥表达是：「这么压手，肯定是真货。」

### 1.5 静水称重的原理

静水称重利用阿基米德原理。样品在空气中称重，再悬挂到水中称重。由于水的浮力，水中重量会变小。空气中重量与水中减轻的重量之间，可以估算比重。

入门公式可以写成：

> 比重 SG = 空气中重量 /（空气中重量 - 水中重量）

不要求小白立刻熟练计算，但要知道它为什么能测：水中少掉的那部分重量，和样品排开水的体积有关。

一个规范的静水称重需要：

| 条件 | 作用 | 常见问题 |
| --- | --- | --- |
| 精度足够的天平 | 小样品误差会被放大 | 普通厨房秤不适合小宝石 |
| 细线或支架稳定 | 减少额外重量和晃动 | 线太粗、支架碰杯会出错 |
| 样品完全浸没 | 浮力计算才有意义 | 未浸没或碰壁会影响读数 |
| 去除气泡 | 气泡会增加浮力 | 裂隙和孔洞更容易挂气泡 |
| 水温和清洁 | 保持条件稳定 | 杂质、油污影响表面状态 |
| 重复测量 | 看结果是否稳定 | 单次读数容易误判 |

静水称重看似简单，实际很考验细节。样品越小，误差越明显；样品越复杂，数据越难解释。教学演示可以帮助理解原理，但不等于每件珠宝都适合自己在家测。

### 1.6 哪些样品会干扰比重判断

比重测试最适合单一材料、裸石、无孔洞、无附着物、大小适中、可安全浸水的样品。很多消费品并不满足条件。

| 样品状态 | 干扰原因 | 消费提醒 |
| --- | --- | --- |
| 镶嵌成品 | 金属和宝石一起称重 | 得到的是整体值，不是宝石 SG |
| 空心结构 | 内部空气影响体积和浮力 | 外观看大不代表密度高 |
| 拼合石 | 多层材料密度不同 | 数据是混合结果，需披露结构 |
| 裂隙多 | 水和气泡进入裂隙 | 读数可能不稳定，还可能损伤样品 |
| 多孔材料 | 吸水或挂气泡 | 不适合随意浸水测试 |
| 有胶/充填 | 附加材料改变重量和体积 | 还可能有稳定性风险 |
| 珍珠/有机宝石 | 对水和环境敏感 | 不建议随意做水中称重 |

成品镶嵌是最常见限制。一枚戒指的重量包含宝石、金属、焊料、镶爪、可能的封底或衬底。你无法从整体重量直接推回宝石密度。空心手镯、空心吊坠和拼合结构也类似：它们的手感和测量值都是结构结果，不是单一材料属性。

### 1.7 比重如何进入证据链

比重数据适合用来「缩小范围」和「排除矛盾」。例如某材料外观像某宝石，但比重明显不在合理范围内，就需要警惕。相反，如果比重接近，也不能说明鉴定完成，因为不同材料可能有接近密度，处理、拼合和成品结构也可能干扰。

更完整的证据链：

| 证据 | 作用 |
| --- | --- |
| 折射率 | 判断光学参数是否匹配 |
| 偏光镜 | 判断 SR、DR、AGG 等光性表现 |
| 比重 | 判断密度范围是否支持 |
| 放大观察 | 看包裹体、裂隙、拼合、处理痕迹 |
| 分光/滤色 | 看颜色和吸收特征 |
| 证书 | 对高价消费提供机构综合结论 |

比重测试结果可以这样表达：「样品在合适条件下测得 SG 约为某范围，与某些材料相符/不符，需要结合 RI、光性和证书继续判断。」不要表达成：「比重对上了，所以肯定真。」

### 1.8 消费边界和红线

本课消费边界：

- 可以把手感当观察描述，不能当鉴定证据。
- 可以理解静水称重原理，不能对所有成品自行测试。
- 可以用 SG 辅助排除材料，不能单独判真假和价格。
- 对镶嵌、空心、拼合、裂隙、多孔和有机材料，要先考虑测试是否适合。

红线包括：

1. 商家只让你「掂一掂」就催促下单。
2. 把整件镶嵌成品重量说成宝石本身密度。
3. 对空心、拼合、充填、裂隙样品不说明结构，却用重量感证明价值。
4. 高价货没有证书和复检，只强调「压手、老料、密度大」。

小白可以追问：「这是裸石还是成品？重量包含哪些部分？是否做过规范比重测试？样品是否适合浸水？证书如何描述材料和处理？是否支持复检？」

## 2. 必背知识卡

### 卡片 1：密度

密度是单位体积的质量，解释同样大小的材料为什么可能重量不同。

### 卡片 2：比重 SG

比重是材料密度相对于水密度的相对值，是宝石材料识别的辅助线索。

### 卡片 3：手感局限

压手感是主观体验，会被尺寸、形状、金属、空心结构和心理预期影响，不能单独判断真假。

### 卡片 4：静水称重

静水称重通过空气中重量和水中重量估算比重，需要精度、去气泡、稳定悬挂和合适样品。

### 卡片 5：成品干扰

镶嵌、空心、拼合、裂隙、多孔和有胶材料会让比重数据失真或难以解释。

### 卡片 6：消费边界

比重数据必须与折射率、偏光镜、放大观察和证书结合，不能替代完整检测。

## 3. 可交互作业

### 作业 1：手感话术判断

请判断下面说法是否稳妥，并说明理由：

1. 这件东西很压手，所以一定是真货。
2. 镶嵌戒指的整体重量不能直接代表宝石比重。
3. 静水称重需要去除气泡并保证样品完全浸没。
4. 比重接近某宝石范围，就可以不看其他证据。

参考方向：

- 第 1 句不稳妥，手感受多因素影响。
- 第 2 句准确，金属和结构会干扰。
- 第 3 句准确，气泡和浸没状态会影响浮力。
- 第 4 句不准确，比重只是证据之一。

### 作业 2：静水称重条件清单

列出做静水称重前需要确认的 6 件事。

参考方向：

- 样品是否为单一材料裸石。
- 是否可以安全接触水。
- 天平精度是否足够。
- 悬挂线或支架是否稳定。
- 是否完全浸没且不碰杯壁。
- 是否去除气泡并重复测量。

### 作业 3：自媒体表达改写

把这句话改成更稳妥的小白学习表达：

> 这个特别压手，密度肯定高，所以一定是真的、很值钱。

建议改写：

> 重量感只能说明我拿起来觉得比较重，但它可能来自体积、金属、结构或心理预期。真假、材料和价值还需要看比重测试条件、折射率、放大观察、证书和复检。
